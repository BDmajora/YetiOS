# YetiOS FreeBSD in-VM assemble package set
#
# These packages are for /assemble inside the FreeBSD VM, not the Artix/Linux
# host pipeline. They are installed only when you boot the image and run:
#
#   ./assemble
#
# /assemble runs with the real FreeBSD kernel/userland and installs into the
# persistent /usr/local UFS partition.
#
# Keep this list boring and explicit. Every package here still needs license
# review before it becomes part of a commercial/default YetiOS image.
